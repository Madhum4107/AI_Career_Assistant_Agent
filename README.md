# AI Career Assistant Agent 🚀

An AI-based Resume Analyzer that extracts skills, calculates score, and predicts job roles using Python.

---

## 📌 Features
- Resume text cleaning
- Skill extraction (Python, Java, JS, AI, SQL etc.)
- Skill scoring system
- Basic job role prediction
- Simple rule-based AI logic

---

## 🧠 How it works
1. Input resume text
2. Clean and process text
3. Extract skills
4. Calculate skill score
5. Predict job role

---

## 🛠️ Tech Stack
- Python
- NLP (basic text processing)
- Rule-based logic
- VS Code

---

## 📁 Project Structure
- main.py → main execution file
- add.py → text processing
- analyzer.py → skill detection
- predictor.py → job role prediction

---

## 📊 Output Example
- Skills Found: Python, JavaScript, AI
- Skill Score: 6
- Predicted Role: Junior Developer
